# Banan — multiplayer

Сайт: https://zursed253-spec.github.io/banan.github.io/

## Игры и количество участников

Все игры в каталоге доступны в диапазоне от 1 до 4 участников. Формат зависит от правил конкретной игры:

- **Одиночные партии против компьютера:** крестики-нолики, морской бой, шахматы, шашки, гомоку, гекс, коридор, сапёр-дуэль, память, «Что пропало?» и «Штурм базы». Для игр с двумя сторонами компьютер делает ответные ходы.
- **Командные игры 2 на 2:** шахматы, шашки, гомоку, гекс, коридор, сапёр-дуэль, «Точки и квадраты», «Четыре в ряд», морской бой и «Штурм базы». При трёх участниках одна команда состоит из двух человек, другая — из одного. В локальной игре можно играть по очереди на одном устройстве.
- **Крестики-нолики:** 2 участника играют на поле 3×3; 3–4 участника — на поле 6×6, где используются X, O, треугольник и квадрат, цель — собрать четыре символа подряд.
- **Карточные игры:** «Дурак», «Последняя карта», «Техасский холдем» и «Королевства» поддерживают 1–4 индивидуальных участника; в одиночном режиме недостающие места занимают боты.
- **Подземелье: Карты судьбы:** кооперативное прохождение на 1–4 участников. В одиночном режиме можно проходить одному.
- **Тактическая арена** временно скрыта из каталога, исходный код сохранён.

Онлайн-комнаты рассчитаны на 2–4 подключённых устройства. Одиночная игра запускается локально и не требует сервера. Для командных игр участники одной команды используют общую сторону и общий счёт.

## Режимы на 1–4 участника

Все игры в каталоге доступны для локальной игры от 1 до 4 участников. В сетевой комнате можно играть вдвоём, втроём или вчетвером; одиночный режим работает локально против ботов или в одиночном кооперативном режиме.

- **Свободная игра:** «Крестики-нолики» остаются индивидуальными. Для 3–4 участников поле расширяется до 6×6, цель — собрать 4 символа подряд; используются отдельные символы для каждого участника.
- **Командные игры:** шахматы, шашки, морской бой, «4 в ряд», Reversi, «Точки и квадраты», Gomoku, Hex, Quoridor, «Сапёр», Memory, «Что пропало?» и Blockade поддерживают две команды. При 3–4 участниках места распределяются по очереди между командами.
- **Карточные игры:** «Дурак», Last Card, Poker и Kingdom используют отдельные места для каждого участника. В локальном покере закрытые карты видит только игрок, чей сейчас ход.
- **Кооператив:** Dungeon — совместное прохождение для 1–4 участников; победа или поражение засчитывается всему отряду.
- **Морской бой локально:** при 2–4 участниках используется режим передачи устройства: каждая сторона отдельно расставляет флот, затем ходит по очереди. В сетевой командной игре флот расставляет капитан команды, а его напарник получает синхронизированное поле.
- **Сетевые комнаты:** после начала партии новые участники не подключаются к уже идущему матчу. Вернитесь в меню комнаты, чтобы открыть набор игроков снова.

## Оформление и шахматы

- Через кнопку «Оформление» в верхней панели можно выбрать светлую или тёмную тему. Выбор сохраняется в браузере.
- В этом же меню доступны три какашки: весёлая, хитрая и сонная. На экран можно поместить до трёх, передвигать мышью или пальцем и удалять нажатием ×. На клавиатуре используйте стрелки для перемещения и Delete для удаления. Расположение сохраняется.
- Шахматная доска использует бежево-коричневую палитру, SVG-фигуры и обозначения полей по краям. В локальной игре доступны отмена хода и поворот доски; для обеих сторон предусмотрены история ходов, специальные правила и обработка ничьих.

## Развёртывание на бесплатном Render

1. Откройте https://dashboard.render.com/blueprints и войдите через GitHub.
2. Выберите **New Blueprint Instance**, затем репозиторий **zursed253-spec/banan.github.io**.
3. Render прочитает render.yaml. Подтвердите создание бесплатного Web Service.
4. После статуса **Live** проверьте адрес Render с /health на конце: JSON должен содержать "ok":true.
5. Откройте страницу игры, в поле «Сервер игры (Render)» укажите URL https://имя-сервиса.onrender.com без /ws.
6. Создайте комнату и отправьте другу скопированную ссылку. Она содержит код комнаты и адрес сервера.

Если Render выдаст адрес banan-zursed253-spec-relay.onrender.com, он уже настроен по умолчанию. Иначе введите фактический URL один раз.

Бесплатный Render засыпает без активности. Первое подключение после простоя может быть медленным.

## Техническая информация

- GitHub Pages размещает index.html, а Node.js WebSocket relay работает на Render.
- Сервер передаёт игровые события между двумя–четырьмя участниками: прямой P2P не нужен. Создатель комнаты выбирает вместимость 2, 3 или 4 игрока; сервер раздаёт каждому место и рассылает события всем остальным участникам.
- Комнаты находятся в памяти сервера и исчезают при его перезапуске.
- /health служит проверкой работоспособности.
- Для локального запуска: cd server, npm install, npm test, npm start.
- Для локального запуска в браузере используйте адрес сервера http://localhost:10000.
